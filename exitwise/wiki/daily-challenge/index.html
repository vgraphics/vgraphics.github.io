Daily challenge

Basics

One board a day, the same for everyone, with monthly rewards.

How it works

  1. 1

    Days you complete count towards this month's milestones: 2 days: 50 coins · 7 days: 100 coins · 13 days: 150 coins and an Auto-play · 19 days: 200 coins and a Grid lines · 25 days: 300 coins and a Magic wand.

  2. 2

    Progress starts again each month.

What it does

Each calendar day has one board, the same for every player. It's harder later in the week, and it has no obstacles.

You can play any day of the current month up to today.

Only the first win of each day pays: 20 coins, plus 5 for perfect.

Good to know

  • Daily runs don't go on the level leaderboards.
