How to play

From the first level

Tap an arrow with a clear path. Clear the board.

How it works

  1. 1

    Start with arrows whose path to the edge is already empty.

  2. 2

    Big boards open zoomed in: pinch or scroll to zoom, and drag to move.

What it does

Every arrow points somewhere. Tap one and it slides off the board along its path, but only if nothing is in its way. The path runs straight on, except where a mirror turns it or a portal carries it across the board.

Clear every arrow to win the level.

Each arrow you clear can only free others, so a level can never become impossible.
