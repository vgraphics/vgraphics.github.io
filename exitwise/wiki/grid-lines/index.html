Powerups

Grid lines

Shows every arrow's path for 5 seconds.

First appears on level 25

What it does

Grid lines draw each arrow's lane to the edge for 5 seconds of play. Anything on a line blocks that arrow.

How to use it

  • Use it on big boards to spot which arrows are free.
  • A pack of 3 costs 150 coins.

Good to know

  • A run that uses a powerup doesn't go on the leaderboard.
